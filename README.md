## Overview

This project is a homepage implementation for **Purelane**, a plant-based homecare brand.

The page was built using the provided homepage reference, with a focus on maintaining:

- Original layout
- Typography
- Colors
- Page sections
- Responsive behavior
- Interactive elements
- Overall visual appearance

The project uses a simple **Vite** setup with **HTML, CSS, and JavaScript**.

---

## Features

- Responsive homepage design
- Mobile-friendly layout
- Purelane brand styling
- Hero section
- Product and content sections
- Responsive navigation
- Interactive page elements
- Smooth scrolling
- Visual transitions
- Responsive typography
- Clean and lightweight project structure
